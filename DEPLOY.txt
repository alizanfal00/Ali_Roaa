رفع الدعوة أونلاين + استقبال الردود
====================================

الجزء 1: رفع الموقع على GitHub Pages (مجاني)
--------------------------------------------
1) اعمل حساب على github.com (لو معندكش).
2) اضغط علامة + فوق يمين > New repository.
   - Repository name: اكتب أي اسم بالإنجليزي بدون مسافات، مثلا  ali-roaa
   - اختار Public
   - دوس Create repository.
3) في صفحة الـ repository دوس على  uploading an existing file  (أو Add file > Upload files).
4) افتح فولدر invitation على جهازك، حدد كل اللي جواه (مش الفولدر نفسه):
      index.html  +  images  +  fonts  +  audio  +  backend  (والصور والموسيقى بتاعتك لو ضفتهم)
   واسحبهم كلهم على الصفحة. مهم: index.html لازم يبقى في أول الـ repository مش جوه فولدر.
5) استنى الرفع يخلص، ودوس Commit changes.
6) روح Settings (تبويب فوق) > Pages (من القايمة الشمال).
   - Source: Deploy from a branch
   - Branch: main  و  / (root)  ثم Save.
7) استنى دقيقة أو اتنين وحدّث الصفحة. هيظهرلك الرابط:
      https://اسم-حسابك.github.io/ali-roaa/
   ده الرابط اللي تبعته للضيوف.

لتعديل أي حاجة بعد كده: افتح الملف في الـ repository > أيقونة القلم > عدّل > Commit changes،
أو ارفع الملف الجديد بنفس الاسم وهيستبدل القديم. التحديث بيظهر بعد دقيقة تقريبا.


الجزء 2: استقبال تأكيد الحضور والتهاني (Google Sheet + إيميل)
-------------------------------------------------------------
GitHub Pages مجرد استضافة للصفحة ومش بيستقبل بيانات، فبنستخدم Google Apps Script (مجاني) كوسيط:
كل رد بيتسجل في جدول Google Sheet وبيجيلك إيميل.

1) افتح sheets.google.com > Blank (جدول جديد). سمّيه مثلا "ردود الدعوة".
2) من القايمة: Extensions > Apps Script.
3) امسح أي كود موجود، وافتح ملف  backend/apps-script.gs  وانسخ كل اللي فيه والصقه.
4) في أول الكود غيّر  PUT_YOUR_EMAIL@gmail.com  لإيميلك. دوس Save (أيقونة الديسك).
5) فوق يمين دوس Deploy > New deployment.
   - دوس الترس جنب Select type > Web app.
   - Execute as: Me
   - Who has access: Anyone
   - دوس Deploy.
6) هيطلب Authorize access: وافق واختار حسابك. لو ظهرلك "Google hasn't verified this app":
   دوس Advanced > Go to (اسم المشروع) > Allow. ده طبيعي لأن الكود بتاعك إنت.
7) انسخ الرابط اللي بيظهر (Web app URL، بيبدأ بـ https://script.google.com/macros/s/ وبينتهي بـ /exec).
8) افتح index.html على GitHub (أو على جهازك)، ودور على السطر:
      const SUBMIT_URL = "";
   والصق الرابط بين علامتي التنصيص، واحفظ/ارفع الملف من جديد.

بعد كده:
- أي حد يأكد حضوره: بيظهر صف جديد في تبويب RSVP (الاسم، جاي ولا لأ، العدد) وبيجيلك إيميل.
- أي حد يبعت تهنئة: بتظهر في تبويب Wishes وبيجيلك إيميل بالرسالة.

اختبار: افتح رابط الموقع، أكد حضور باسم تجريبي، وبعدها بص على الجدول والإيميل (ممكن ياخد ثواني).

ملاحظات:
- لو غيرت في كود Apps Script بعد النشر: Deploy > Manage deployments > القلم > Version: New version > Deploy (الرابط بيفضل ثابت).
- لو سبت SUBMIT_URL فاضي، الفورمين بيفتحوا واتساب بدل كده (بالرقم اللي في WHATSAPP).
- رابط الـ Apps Script بيبان في كود الصفحة، فممكن حد يبعت ردود وهمية. الكود بيحدد طول الرسائل وبيمنع الصيغ، والأسوأ إنك تلاقي صفوف زيادة تمسحها.
- لو عايز الإيميل يوصل على أكتر من عنوان: حط الإيميلات في OWNER_EMAIL مفصولة بفاصلة.
