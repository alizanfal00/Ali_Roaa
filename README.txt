دعوة خطوبة علي ورؤى
=====================

التشغيل
-------
1) فك الضغط، وافتح الفولدر "invitation" في VS Code (File > Open Folder).
2) كليك يمين على index.html > Open with Live Server (أو زرار Go Live تحت).

ملاحظة: لازم تفتح الفولدر كله مش ملف index.html لوحده، علشان الصور والخطوط تتحمل.

حاجات لازم تعدلها
-----------------
- رقم واتساب: في آخر index.html ابحث عن  WHATSAPP  وحط رقمك بصيغة دولية بدون + (مثال: 201012345678).
  أي رسالة تأكيد حضور أو تهنئة بتتبعت على الرقم ده.
- الساعة: حاليا 7:00 مساء. غيّرها في سطر  EVENT  (آخر الملف)، وفي نص "Thursday · 07:00 PM" في قسم Reception Venue.
- صور العروسين: حط صورتين باسم  images/ali.jpg  و  images/roaa.jpg  (مربعة، 600x600 أو أكتر).
  لو مش موجودين بيظهر حرف A و R بدلهم.
- الموسيقى: حط ملف باسم  audio/music.mp3  وهتشتغل أول ما الضيف يدوس Open، وزرار الدايرة الذهبية بيوقفها.

النزول التلقائي
---------------
بعد ما الضيف يدوس Open، الصفحة بتنزل لوحدها ببطء، وبتقف أول ما يلمس الشاشة أو يستخدم السكرول أو الكيبورد.
تقدر تتحكم فيه من أول الـ script في index.html:
  AUTO_SCROLL = false     لإلغائه
  AUTO_SPEED              سرعة النزول (hero = أول قسم أبطأ، rest = باقي الصفحة)
  AUTO_DELAY              الانتظار قبل ما يبدأ (بالمللي ثانية)

الشاشات
-------
الصفحة بتتأقلم تلقائيا: موبايل (عمود واحد)، تابلت، ولاب (قسم العد التنازلي والتقويم جنب بعض،
والخريطة جنب التفاصيل، وRSVP جنب الـ Guestbook، والورد والخطوط بتكبر).

فولدرات المشروع
---------------
images/  الورد والفاصل الزخرفي
fonts/   خطوط Cormorant Garamond و DM Sans
audio/   الموسيقى (فاضي لحد ما تضيف الملف)
